# SWYF Cloud TTS — повний посібник

Мод для **Scam With Your Friends**, який замінює локальний QwenTTS на хмарний синтез мовлення.

Гра запускає `QwenTtsWorker.exe` як окремий процес і спілкується з ним бінарним протоколом через
stdin/stdout. Цей проєкт — повноцінна заміна того процесу: він говорить тим самим протоколом, але
замість GGUF-моделі відправляє текст у хмару й повертає аудіо у форматі, який очікує гра
(24 кГц, float32, моно).

Жодних змін у бінарниках гри. Оригінальний воркер зберігається поруч як `QwenTtsWorker.orig.exe`.

---

## Що це дає

| | Локальний Qwen | Цей мод |
|---|---|---|
| Час до першого звуку | 60+ с (завантаження моделі) | ~1–5 с, залежно від провайдера |
| Навантаження на CPU/GPU | високе | майже нульове |
| Якість і голоси | посередня, один голос | залежить від провайдера, окремий голос на персонажа |
| Потрібен інтернет | ні | так |
| Ціна | безкоштовно | залежить від провайдера (див. нижче) |

Гра ріже мовлення на шматки по ~240 символів і чекає на кожен шматок не довше 30 секунд,
тож хмарних 1–8 с на репліку вистачає із запасом. Повторні репліки віддаються з кешу миттєво.

## Встановлення

Потрібні Windows 10/11 x64 і встановлена гра.

1. Завантажте `SWYF-CloudTTS-Setup-vX.Y.Z.exe` зі сторінки Releases.
2. Запустіть його. Інсталятор сам знаходить гру через Steam (або натисніть «Огляд…»).
3. Натисніть **Встановити**.
4. Запустіть гру: **Settings → Speech → CLOUD TTS** — оберіть провайдера, вставте API-ключ,
   натисніть **Apply**, потім **Test voice**.

Що робить інсталятор:

1. зберігає оригінальний воркер як `QwenTtsWorker.orig.exe`, а маніфест — як
   `runtime-manifest.json.swyf-backup`;
2. кладе хмарний воркер у `Scam With Your Friends_Data\StreamingAssets\kolkata-qwen-runtime`;
3. оновлює SHA-256 у `runtime-manifest.json` (гра перевіряє хеш кожного файлу рантайму);
4. встановлює Unity Doorstop (`winhttp.dll`, `doorstop_config.ini`) і картку налаштувань
   у теку `SwyfCloudTts` гри; якщо там уже є інший завантажувач модів, картку пропускає,
   щоб його не зламати (голоси при цьому працюють);
5. зберігає копії воркера й інсталятора в `%LOCALAPPDATA%\SWYF-CloudTTS\bin` і додає запис
   **SWYF Cloud TTS** у «Параметри → Програми» (кнопки «Змінити» та «Видалити»).

Права адміністратора зазвичай не потрібні: теки Steam доступні для запису. Якщо гра лежить
у захищеній теці, інсталятор попросить підвищення прав лише для цієї операції.

### Після оновлення гри

Steam-оновлення повертає оригінальний воркер і маніфест. Відкрийте інсталятор (той самий файл або
«Параметри → Програми → SWYF Cloud TTS → Змінити») — він покаже «Вимкнено оновленням гри» —
і натисніть **Відновити**.

### Командний рядок інсталятора

```powershell
SWYF-CloudTTS-Setup.exe --status                 # стан встановлення
SWYF-CloudTTS-Setup.exe --install --quiet        # без вікна, код виходу 0 = успіх
SWYF-CloudTTS-Setup.exe --uninstall --quiet [--purge]
SWYF-CloudTTS-Setup.exe --game "E:\SteamLibrary\steamapps\common\Scam With Your Friends"
SWYF-CloudTTS-Setup.exe --lang uk|ru|en
```

Журнал інсталятора: `%LOCALAPPDATA%\SWYF-CloudTTS\setup.log`.

## Провайдери

| `provider` | Що робить | Ключ |
|---|---|---|
| `googleai` (рекомендовано) | Gemini TTS, безкоштовний тариф, без клонування | ключ Google AI Studio |
| `elevenlabs` | найкраща якість; на Starter клонує голос **кожного персонажа**, на безкоштовному Free дає стандартні й ваші власні голоси | `sk_...` |
| `openai` | `gpt-4o-mini-tts`, дешево, без клонування | `sk-...` |
| `qwenremote` | Qwen3-TTS на власній/орендованій GPU; клонує голос кожного персонажа | не потрібен, лише URL (токен — за потреби) |
| `mock` | офлайн-тони замість мовлення, для перевірки протоколу | не потрібен |
| `silent` | тиша, гра не ламається | не потрібен |
| `passthrough` | віддає запити оригінальному локальному Qwen | не потрібен |

`mock`, `silent` і `passthrough` існують для діагностики: якщо з ними гра поводиться нормально,
а з хмарою — ні, проблема в мережі, ключі або квоті, а не в інтеграції.

Hume AI (Octave) прибрано у 1.3: Hume закриває свої TTS та EVI API 13 листопада 2026 і після цього
видаляє дані акаунтів. Конфіг із `"provider": "hume"` перемикається на Google AI.

### Повністю безкоштовно: ElevenLabs Free

Найпростіший спосіб грати без оплати.

1. Зареєструйтеся на <https://elevenlabs.io> (тариф **Free**, картка не потрібна).
2. **Developers → API keys → Create API key**. Обмеження ключа можна не вмикати; якщо вмикаєте, дозвольте
   **Text to Speech** і **Voices: Read**.
3. У грі: **Settings → Speech → CLOUD TTS** → сервіс **ElevenLabs**, вставте ключ, **Застосувати**,
   потім **Перевірити голос**.

Що ви отримаєте:

- Кожен персонаж говорить одним із 21 стандартного голосу ElevenLabs, підібраним за статтю й висотою
  голосу з гри. Клонування на Free немає; мод бачить це сам і не намагається клонувати.
- До **3 власних голосів**, створених за описом: elevenlabs.io → **Voices → Create a voice → Voice Design**,
  наприклад «старий бурчливий бос, хрипкий голос, говорить повільно» → **Save**. У картці натисніть
  **Завантажити мої голоси**, і голос з'явиться у списках: оберіть його для боса в **CHARACTERS** або як
  **Загальний голос**, якщо хочете, щоб усі говорили ним.
- **10 000 кредитів на місяць.** Моделі `eleven_v4_turbo` (типова) і `eleven_flash_v2_5` витрачають
  пів кредиту на символ, тож виходить близько 20 000 символів, приблизно 20 хвилин мовлення.
  Коли кредити закінчаться, репліки будуть тихими до оновлення ліміту.
- Безкоштовний тариф лише для некомерційного використання й дозволяє 2–4 одночасні запити.

Якщо ElevenLabs відповідає `detected_unusual_activity`, вимкніть VPN або проксі: безкоштовні акаунти
блокуються за підозрілої активності.

### Google AI (Gemini TTS)

- Ключ безкоштовний: <https://aistudio.google.com/apikey>.
- Модель за замовчуванням `gemini-3.8-flash-tts`, ендпоінт `POST /v1beta/interactions`.
- Відповідь — `audio/l16`, 24 кГц; мод конвертує її у float32 і віддає грі.
- Українська та російська мови підтримуються.
- Довгі репліки автоматично ріжуться на шматки до 600 символів.
- Безкоштовний тариф Gemini TTS покриває і вхід, і вихід; ліміти — у консолі Google AI Studio.
- Клонування голосу не підтримується: голос обирається зі списку 30 студійних голосів
  (Kore, Puck, Charon, Aoede, Leda, Fenrir, Orus, Zephyr та інші) або автоматично за статтю персонажа.
  Список вбудований у картку, тому працює навіть без ключа й без мережі.

### ElevenLabs

- Моделі (ID пишуться в `elevenlabs.modelId`):

  | Модель | Ціна за 1k символів | Мови | Латентність | Ліміт на запит |
  |---|---|---|---|---|
  | `eleven_v4_turbo` | **$0.04** | 94 | ~100 мс | 10 000 символів |
  | `eleven_v4` | $0.08 | 94 | ~250 мс | 10 000 |
  | `eleven_v3` | $0.08 | 74 | ~600 мс | 5 000 |
  | `eleven_flash_v2_5` | $0.04 | 32 | ~75 мс | 40 000 |
  | `eleven_multilingual_v2` | $0.08 | 29 | ~400 мс | 10 000 |

  За замовчуванням тепер `eleven_v4_turbo`: виразність v4, вдвічі дешевша за v3/v4, найнижча
  затримка й найточніше клонування (IVC і PVC підтримані). Клонування в v4/v4 turbo
  найточніше за всі попередні моделі.
- **Клонування й ротація.** З `autoClone` кожен персонаж говорить клоном свого голосу з гри. Клонування
  доступне з плану **Starter**; ключ має мати дозволи `voices_read` і `voices_write`.
  Обмеження акаунта, з якими працює мод (Starter, жовтень 2026):

  | Ліміт | Starter | Що робить мод |
  |---|---|---|
  | Слоти голосів | 10 | Коли слоти зайняті, видаляє клон персонажа, якого найдовше не чули, і клонує нового. Першими йдуть «сироти» — клони `swyf-…`, які не прив'язані до жодного персонажа. |
  | Додавання голосів за місяць | 65 | Кожен новий клон — одне додавання. Останні `reserveVoiceEdits` (типово 5) мод лишає вам; після цього нові персонажі до кінця місяця отримують стандартні голоси. |

  - Видаляються **лише** голоси з назвою `swyf-<персонаж>`; ваші власні голоси мод не чіпає.
  - Клон, який уже є в акаунті (наприклад, гра обірвала репліку, поки мод зберігав його), використовується
    повторно й не витрачає додавання.
  - **Keep** у списку CHARACTERS захищає клон від ротації — зручно для боса, який говорить щодня.
  - Перша репліка нового персонажа чекає на клонування (~3–4 с, разом із видаленням і стрімінгом — до ~9 с).
    Гра чекає першого звуку до 20 с і обриває репліку, якщо почалася наступна.
  - Кеш аудіо прив'язаний до персонажа, а не до id клону, тож після ротації повторні репліки персонажа
    звучать із кешу без нового клонування.
  - Стан ротації (коли кого чули, паузи після помилок, останні цифри акаунта) лежить у
    `%LOCALAPPDATA%\SWYF-CloudTTS\elevenlabs-clones.json`; картка в грі показує з нього слоти та ліміт.
- **Без клонування** (або коли воно на паузі) персонаж отримує один із 21 стандартних голосів ElevenLabs
  за статтю й тоном. Стандартні голоси слотів не займають. Свій голос можна обрати в CHARACTERS або
  як глобальний (`defaultVoiceId`); порожнє значення — автовибір.
- Озвучка йде через стрімінговий ендпоінт `/text-to-speech/{voice}/stream`, тож гра отримує перший
  звук задовго до кінця генерації.
- **Типові помилки й що з ними робити:**
  | Помилка | Причина | Розв'язок |
  |---|---|---|
  | `401 ... missing the permission voices_write` / `voices_read` | ключ не може клонувати або читати голоси | ElevenLabs → Developers → API keys → увімкнути **Voices Read** і **Voices Write**; мод робить паузу на 30 хв і говорить стандартними голосами |
  | `You have reached your maximum amount of custom voices` | слоти зайняті | ротація звільняє слот сама; якщо всі слоти — ваші власні голоси або персонажі з **Keep**, клонування стає на паузу |
  | `402` або пауза «цей тариф не клонує голоси» | тариф Free | нічого: персонажі говорять стандартними голосами; для клонів потрібен Starter |
- Перевірити без гри (використовує збережений кліп персонажа з `voices\`):

```powershell
QwenTtsWorker.exe --test --provider elevenlabs --speaker 512aec8e4ae7eae0 --text "Алло, слухаю вас."
```

### Qwen3-TTS на власній GPU

Якщо ви орендували відеокарту (RunPod, Vast.ai, власний сервер), підніміть на ній Qwen3-TTS з
OpenAI-сумісним API. Найпростіший варіант — образ `k8bit/qwen3-tts`:

```bash
docker run -d --name qwen3-tts --gpus all \
  -p 8000:8000 -p 8001:8001 \
  -v /workspace/data:/data \
  -v /workspace/voices:/voices:ro \
  k8bit/qwen3-tts:latest
```

- Порт **8000** — REST API (Swagger на `/docs`, перевірка на `/health`), порт **8001** — Gradio UI.
- `/data` — кеш ваг моделі; без нього 1.7 ГБ завантажуються заново після кожного перезапуску контейнера.
- На RunPod опублікуйте TCP-порт 8000; адреса буде виглядати як
  `https://<pod-id>-8000.proxy.runpod.net`.
- Модель (~1.7 ГБ) завантажується при першому старті; доки вона вантажиться, API відповідає 503.
- Голоси для режиму «готовий голос» — файли в `/voices`: `kate.wav` (+ необов'язковий `kate.txt` із
  транскриптом, він покращує перенесення інтонації). Список віддає `GET /v1/audio/voices`.
- VRAM: 0.6B Base — ~3 ГБ, 1.7B — ~6 ГБ. Карти на 8–12 ГБ достатньо.

Два режими:

| `qwenremote.mode` | Що надсилається | Коли використовувати |
|---|---|---|
| `clone` (типово) | `POST /v1/audio/speech/clone`, multipart із референсним кліпом персонажа з гри | найкраща відповідність голосу; перша репліка персонажа повільніша |
| `voice` | `POST /v1/audio/speech` із назвою голосу, який уже лежить у `/voices` | швидше, але без мапінгу всі говорять одним голосом |
| `design` | `POST /tts` з `{"text", "voice_prompt", "language"}` | власний сервер, де є лише VoiceDesign-обгортка (див. нижче) |

Якщо сервер запущений у режимі CustomVoice, `/clone` відповідає `400`; мод один раз попереджає в
`worker.log` і далі використовує `voice` (тому для такого сервера задайте голос).

Якщо `/v1/audio/speech` відповідає `404` або `405`, мод один раз пробує `POST /tts` і, якщо той
працює, запам'ятовує цей сервер до кінця сесії. Тобто режим `clone` можна залишити — просто
вкажіть правильну адресу.

```json
"qwenremote": {
  "baseUrl": "http://127.0.0.1:8000",
  "apiKey": "",
  "mode": "clone",
  "model": "tts-1",
  "voice": "",
  "language": "auto",
  "instruct": null
}
```

- `baseUrl` приймає і `http://host:8000`, і `http://host:8000/v1`.
- `apiKey` необов'язковий: якщо проксі/сервер вимагає токен, він піде як `Authorization: Bearer`.
  Для режиму `design` ключ додатково надсилається як `X-API-Key`.
- `language`: `auto` = мова гри. **Української в Qwen3-TTS немає** — для українського тексту
  оберіть `English` або `Russian` (або залиште `auto`, якщо гра йде російською).
- `instruct` — підказка манери для режиму `voice` (у більшості збірок у `clone` ігнорується).
  У режимі `design` це голос персонажа: текст опису, наприклад `Young male voice, energetic`.

#### Власний сервер з одним ендпоинтом `/tts`

Якщо на GPU піднято власну FastAPI-обгортку (типовий приклад — `utils/server.py` з Qwen3-TTS
VoiceDesign), то вона має лише `POST /tts`:

```json
{ "text": "...", "voice_prompt": "Young male voice, energetic", "language": "Russian" }
```

Заголовок авторизації — `X-API-Key`. Такий сервер переводять у режим `design`:

```json
"qwenremote": {
  "baseUrl": "http://127.0.0.1:8000",
  "apiKey": "ваш-X-API-Key",
  "mode": "design",
  "language": "Russian",
  "instruct": "Young male voice, energetic, clear diction."
}
```

Голос тоді однаковий для всіх персонажів (сервер щоразу вигадує його з опису), тому в `instruct`
варто задати конкретну манеру. Клонування на такому сервері неможливе — для справжнього
клонаування персонажів підніміть образ `k8bit/qwen3-tts` (Base) і використовуйте режим `clone`.

#### Пряме підключення через SSH-тунель

Якщо GPU орендована й доступ до неї є лише по SSH, зробіть на своєму комп'ютері тунель:

```powershell
ssh -L 8000:localhost:8000 -p 3202 root@<host>
```

- `-p 3202` — це **порт SSH**, а `-L 8000:localhost:8000` — **порт API на вашому комп'ютері**.
  У `qwenremote.baseUrl` треба вказувати саме `http://127.0.0.1:8000` (не 3202).
- Тунель має бути запущений весь час, поки граєте: інакше мод напише `cannot reach ...`.
- Перевірити, що порт слухається: `Test-NetConnection -ComputerName 127.0.0.1 -Port 8000`.

Клонування на невеликій GPU займає 2–8 с, тому для цього провайдера варто підняти таймаут:
`"network": { "timeoutSeconds": 20, "maxAttempts": 1 }` (добуток має лишатися нижче 25 с).

Перевірка без гри:

```powershell
QwenTtsWorker.exe --test --provider qwenremote --base-url http://127.0.0.1:8000 `
    --mode clone --language Russian --text "Привіт, це тест."
```

Якщо в кеші вже є референсний кліп персонажа, `--test` використає його й перевірить саме клонування;
інакше перемкнеться на `voice` і попросить `--voice`.

Для власного сервера з `/tts`:

```powershell
QwenTtsWorker.exe --test --provider qwenremote --base-url http://127.0.0.1:8000 `
    --mode design --language Russian --key <ваш-X-API-Key> --text "Привіт, це тест."
```

## Голоси персонажів

Гра не повідомляє, хто саме говорить. Вона надсилає 2.4k–240k семплів референсного кліпу персонажа —
це стабільний відбиток. Мод рахує з нього SHA-256, зіставляє з `voices.json` і закріплює голос за
спікером.

У картці гри є блок **CHARACTERS** (кнопка **Show list**):

- **Play** — послухати, як персонажа озвучує сама гра (оригінальний кліп);
- поле імені — підпис лише для вас;
- голос для поточного сервісу: список для Google AI, OpenAI та ElevenLabs (стандартні голоси й ваші
  власні після **Завантажити мої голоси**), для Qwen3-TTS — назва голосу на сервері;
- **Авто** повертає автоматичний голос, **Скинути всі голоси** — для всіх персонажів;
- для ElevenLabs — **Не видаляти**: клон цього персонажа ніколи не потрапляє під ротацію (наприклад, бос).

Зміни зберігаються одразу й діють з наступної репліки: воркер перечитує `voices.json`, щойно
файл змінюється.

**Auto** означає: глобальний голос провайдера, якщо його задано, інакше — голос із пулу за
висотою тону персонажа (нижче 165 Гц — чоловічий). Автовибір детермінований і ніде не
записується, тож зміна глобального голосу впливає на всіх персонажів без власного вибору.
Для ElevenLabs порожнє поле означає автоклонування (якщо ввімкнено) або глобальний голос.

Формат `%LOCALAPPDATA%\SWYF-CloudTTS\voices.json`:

```json
{
  "speakers": {
    "3f9a1c0b7d2e4a55": {
      "label": "Jake",
      "gender": "male",
      "pitchHz": 112.4,
      "voices": { "googleai": "Charon", "openai": "onyx", "elevenlabs": "4GZHXTLupAdLa8Iwa6du" }
    }
  }
}
```

Хеші й тони пишуться в `worker.log` (`new speaker <hash>: pitch=... Hz`), а референсні кліпи
лежать у `voices\<hash>.wav`.

## Налаштування в грі (Settings → Speech)

У паузі **Settings → Speech** з'являється картка **CLOUD TTS**. Вона зібрана з тих самих рядків, класів
і шрифтів, що й власні налаштування гри, тож виглядає як її частина:

- **Мова панелі** — English, українська або російська. «Авто» бере російську, якщо гра російською,
  українську, якщо українська Windows, інакше англійську. Вибір зберігається одразу.
- **Хмарні голоси для** — це власне налаштування гри «Qwen» (той самий ключ `Kolkata.Qwen3Tts`), тому
  її рядок ховається, поки є картка. За замовчуванням гра віддає в хмару всі дзвінки, крім англійських;
  «Усіх дзвінків» вмикає хмару і для англійської, «Вимкнено» повертає власні голоси гри.
- Під ним картка попереджає, якщо гра ще завантажує свої голосові файли (≈1,3 ГБ: без них гра не
  звертається до озвучувача) або вимкнула хмарні голоси до перезапуску після невдалої репліки.
- Сервіс, ключ, модель і голос («Інше…» дозволяє ввести будь-який id), параметри сервісу, мережа й кеш,
  тестова фраза та список персонажів.

**Застосувати** зберігає налаштування й перезапускає воркер — гру перезапускати не треба.
**Перевірити голос** озвучує фразу з поточними значеннями форми (без збереження) і програє її через
аудіо гри.

### Як це працює

Гра постачається з **обрізаним mscorlib** — у ньому немає `MethodBase.GetMethodBody`,
`File.ReadAllLines`, `BitConverter.ToSingle`, `Stack<T>` та багато чого іншого, тому
Harmony/IL-патчинг і BepInEx тут не працюють. Замість цього використовується маленька точка входу
Unity Doorstop (`SwyfCloudTts.Boot.dll`): вона чекає завантаження першої сцени, створює
`MonoBehaviour` і раз на секунду шукає `PauseMenuToolkitController`, доки не знайде
`speech-screen`, куди додається картка. Жоден DLL гри не змінюється.

Обидві збірки компілюються проти **власних** `mscorlib.dll`, `System.dll` і `System.Core.dll` гри
(див. `plugin/Directory.Build.targets`), тож виклик API, якого в грі немає, стає помилкою збірки,
а не `MissingMethodException` під час гри.

### Логи

| Що | Шлях |
|---|---|
| Завантаження Doorstop | `%LOCALAPPDATA%\SWYF-CloudTTS\boot.log` |
| Робота картки | `%LOCALAPPDATA%\SWYF-CloudTTS\plugin.log` |

`plugin.log` ротується на 1 МБ.

**Якщо після логотипу чорний екран** — почніть з `boot.log`. Відома причина: виклик
`UnityEngine.Debug.Log` з точки входу Doorstop до ініціалізації логера Unity ламає
`DebugLogHandler` у всьому процесі, тому boot-код пише **тільки у файл**.

## Конфігурація

Файл: `%LOCALAPPDATA%\SWYF-CloudTTS\cloud-tts.config.json`

Конфіг редагує картка в грі; вручну його правити не обов'язково. Воркер бере шлях із `--config`,
потім зі змінної `SWYF_TTS_CONFIG`, інакше — цей файл. Конфіг зі старих версій (поруч із воркером
у теці гри) переноситься сюди автоматично.

```json
{
  "provider": "googleai",
  "openai": {
    "apiKey": "",
    "baseUrl": "https://api.openai.com/v1",
    "model": "gpt-4o-mini-tts",
    "voice": null,
    "instructions": null,
    "speed": null
  },
  "elevenlabs": {
    "apiKey": "",
    "baseUrl": "https://api.elevenlabs.io/v1",
    "modelId": "eleven_v4_turbo",
    "autoClone": true,
    "defaultVoiceId": "",
    "reserveVoiceEdits": 5,
    "stability": 0.5,
    "similarityBoost": 0.8
  },
  "googleai": {
    "apiKey": "",
    "baseUrl": "https://generativelanguage.googleapis.com/v1beta",
    "model": "gemini-3.8-flash-tts",
    "voiceId": "",
    "style": "natural, conversational"
  },
  "qwenremote": {
    "apiKey": "",
    "baseUrl": "http://127.0.0.1:8000",
    "mode": "clone",
    "model": "tts-1",
    "voice": "",
    "language": "auto",
    "instruct": null
  },
  "cache": { "enabled": true, "maxMegabytes": 512, "clearOnVoiceChange": true },
  "fallback": { "passthrough": false, "originalExe": "QwenTtsWorker.orig.exe" },
  "network": { "timeoutSeconds": 12, "maxAttempts": 2 },
  "logging": { "verbose": false }
}
```

Ключі можна не писати у файл, а тримати у змінних середовища (мають пріоритет):

- `SWYF_TTS_GOOGLEAI_KEY` (або `GOOGLE_API_KEY`, `GEMINI_API_KEY`)
- `SWYF_TTS_ELEVENLABS_KEY`
- `SWYF_TTS_OPENAI_KEY`
- `SWYF_TTS_QWENREMOTE_URL` — адреса сервера Qwen3-TTS
- `SWYF_TTS_QWENREMOTE_KEY` (або `QWEN_TTS_API_KEY`) — необов'язковий токен сервера

### Важливі поля

| Поле | Навіщо |
|---|---|
| `googleai.voiceId` | порожньо = авторозподіл по спікерах; `Kore`, `Puck`, `Charon`… = один голос на всіх |
| `googleai.style` | стиль мовлення, напр. `"natural, conversational"` |
| `openai.voice` | `null` = авторозподіл; значення = один голос на всіх |
| `openai.instructions` | стиль мовлення, напр. `"Speak like an angry Scottish fisherman"` |
| `openai.speed` | 0.25–4.0 |
| `qwenremote.baseUrl` | адреса API, напр. `http://127.0.0.1:8000` або `https://<pod>-8000.proxy.runpod.net` |
| `qwenremote.mode` | `clone` — клонувати голос персонажа з гри; `voice` — готовий голос із `/voices`; `design` — власний сервер `POST /tts` |
| `qwenremote.voice` | назва файлу в `/voices` (без розширення); для `voice` обов'язкова |
| `qwenremote.language` | `auto` = мова гри; української в Qwen3-TTS немає, тому `English`/`Russian` |
| `qwenremote.instruct` | підказка манери для `voice`; у `design` — опис голосу, який сервер перетворить у тембр |
| `network.timeoutSeconds` | бюджет на один запит. Добуток таймаут × спроби тримайте **нижче 25 с**, інакше гра встигне скасувати шматок |
| `network.maxAttempts` | 2 = один повтор при 5xx/таймауті |
| `cache.clearOnVoiceChange` | очищати кеш, коли **Apply** змінює голос або провайдера |
| `cache.maxMegabytes` | стеля дискового кешу; старі файли видаляються за LRU |
| `elevenlabs.reserveVoiceEdits` | скільки місячних додавань голосів мод лишає вам (типово 5) |
| `elevenlabs.defaultVoiceId` | порожньо = стандартний голос за статтю для персонажів без клону |
| `fallback.passthrough` | **типово вимкнено:** локальна модель вантажиться довше, ніж гра чекає першого звуку (20 с); пробується, лише якщо хмара відмовила за перші 5 с |
| `logging.verbose` | логувати текст реплік і вибір голосу |

### Де що лежить

| Що | Шлях |
|---|---|
| Конфіг | `%LOCALAPPDATA%\SWYF-CloudTTS\cloud-tts.config.json` |
| Логи воркера | `%LOCALAPPDATA%\SWYF-CloudTTS\worker.log` |
| Логи плагіна | `%LOCALAPPDATA%\SWYF-CloudTTS\boot.log`, `plugin.log` |
| Голоси | `%LOCALAPPDATA%\SWYF-CloudTTS\voices.json` |
| Референсні кліпи | `%LOCALAPPDATA%\SWYF-CloudTTS\voices\<hash>.wav` |
| Кеш аудіо | `%LOCALAPPDATA%\SWYF-CloudTTS\cache\*.pcm` |
| Копії воркера й інсталятора | `%LOCALAPPDATA%\SWYF-CloudTTS\bin\` |
| Журнал інсталятора | `%LOCALAPPDATA%\SWYF-CloudTTS\setup.log` |
| Стан ротації ElevenLabs | `%LOCALAPPDATA%\SWYF-CloudTTS\elevenlabs-clones.json` |
| Лог гри | `%USERPROFILE%\AppData\LocalLow\Jatater Worldwide\Scam With Your Friends\Player.log` |

Кеш ключується за `SHA256(провайдер | голос | модель | стиль | мова | текст)`. Повторні репліки
(привітання, бойові вигуки) віддаються з диска за ~5 мс і не коштують нічого.
Відповіді-заглушки (тиша після помилки) в кеш не потрапляють.

## Командний рядок

`QwenTtsWorker.exe` без аргументів — звичайний режим воркера (його запускає гра).
Для ручних перевірок є окремі режими:

```powershell
QwenTtsWorker.exe --version
QwenTtsWorker.exe --help
QwenTtsWorker.exe --print-config
QwenTtsWorker.exe --test --text "Привіт, це тест." --out test.wav
QwenTtsWorker.exe --test --provider mock
QwenTtsWorker.exe --test --provider googleai --voice Kore --key AIza...
QwenTtsWorker.exe --list-voices   # власні голоси ElevenLabs -> elevenlabs-voices.json
QwenTtsWorker.exe --test --provider qwenremote --base-url http://127.0.0.1:8000 --mode clone
QwenTtsWorker.exe --test --provider qwenremote --base-url http://127.0.0.1:8000 --mode voice --voice kate
```

`--test` не пише в кеш, тому його можна запускати навіть під час гри. ElevenLabs клонує голос у
`--test` лише коли ввімкнено `autoClone` і в `voices\` уже є кліп із гри.
`--config <path>` підміняє шлях до конфігу в будь-якому режимі.

## Діагностика

**Гра мовчить.**
Натисніть **Test voice** у картці гри — помилку буде видно там. Повний журнал:
`%LOCALAPPDATA%\SWYF-CloudTTS\worker.log`. Найчастіші причини:
`provider 'googleai' has no credentials` (немає ключа), `401` (ключ невірний), `429` (квота),
`402` (платний план ElevenLabs), `429 ... requests per day` (вичерпано добовий ліміт безкоштовного
тарифу Gemini TTS), `no audio within 15 s` (сервіс не встиг; гра чекає не довше 20 с),
`provider 'qwenremote' has no valid server URL`
(не задано `qwenremote.baseUrl`). Кожна помилка супроводжується
попередженням, а гра отримує 50 мс тиші замість збою.

**Qwen3-TTS: 401/403, 404 або 503.**
`401/403` — сервер вимагає токен, заповніть `qwenremote.apiKey`. `404` — неправильний порт або URL
(потрібен саме REST API на 8000, а не Gradio на 8001). `503` — модель ще вантажиться, зачекайте
хвилину. `400/422` у режимі `clone` означає, що сервер не вміє клонування: увімкніть `mode: "voice"`
і задайте голос із `/voices`.

Якщо сервер не відповідає взагалі (`cannot reach http://127.0.0.1:8000`), перевірте, що SSH-тунель
запущений і що в `baseUrl` вказано локальний порт тунелю, а не порт SSH. Крім того, мод сам
пробує `POST /tts`, якщо `/v1/audio/speech` відповів `404` — у лог при цьому з'явиться
`using the server's /tts VoiceDesign endpoint`.

**Гра довго думає перед першою реплікою.**
Значить, вона все ще вантажить локальну модель — мод не встановлено або його вимкнуло оновлення гри.
Відкрийте інсталятор: має бути «Встановлено, версія …»; якщо ні — натисніть **Відновити**.

**`Player.log` пише про невідповідність хешу.**
`runtime-manifest.json` не оновлено. Відкрийте інсталятор і натисніть **Відновити** (або **Видалити** для відкату).

**Чорний екран після логотипу.**
Перевірте `boot.log`: якщо там `entrypoint` і `host created`, значить завантаження пройшло.
Дивіться `Player.log` на `MissingMethodException`. Щоб швидко повернути гру, видаліть мод
інсталятором і додайте `boot.log` та `Player.log` до звіту про помилку.

**Картка не з'явилася в Settings → Speech.**
`plugin.log` має містити `PauseMenuToolkitController resolved` і `Cloud TTS section added`.
Якщо рядків немає — Doorstop не завантажився: перевірте `doorstop_config.ini`
(`target_assembly = SwyfCloudTts\SwyfCloudTts.Boot.dll`) і наявність `winhttp.dll` у теці гри.

**Білі поля/кнопки в картці.**
Плагін задає темну тему inline для кожного контрола, бо USS гри не покриває нові UI Toolkit елементи.
Якщо тема знову «світла», значить встановлена стара версія `SwyfCloudTts.Plugin.dll` — натисніть
**Перевстановити** в інсталяторі.

**Звук є, але не той голос.**
Блок **ПЕРСОНАЖІ** у картці → оберіть потрібний голос або «Авто».

**Перші секунди тиші, далі нормально.**
Перший запит до ElevenLabs включає клонування голосу — це кілька секунд. Далі все з кешу.

## Перевірка без гри

`tools/probe.py` запускає воркер точно так, як це робить гра, і зберігає відповідь у WAV.
Потрібен `ffmpeg` у PATH (для декодування референсу).

```powershell
python tools\probe.py --exe dist\QwenTtsWorker.exe `
    --ref "C:\Program Files (x86)\Steam\steamapps\common\Scam With Your Friends\Scam With Your Friends_Data\StreamingAssets\kolkata-voices\audio.wav" `
    --text "Привіт, це тест." --lang Russian `
    --provider mock --out test.wav --repeat 2
```

Другий запуск з `--repeat 2` показує роботу кешу (перший — синтез, другий — кілька мілісекунд).

Для перевірки HTTP-шару без витрат і без ключа є локальні заглушки:

```powershell
# Gemini Interactions API
python tools\fake_gemini.py 9099
QwenTtsWorker.exe --test --provider googleai --key test `
    --config google.config.json   # baseUrl = http://127.0.0.1:9099/v1beta

# OpenAI
python tools\fake_openai.py --port 8799
python tools\probe.py --exe dist\QwenTtsWorker.exe --ref ... `
    --provider openai --openai-base-url http://127.0.0.1:8799/v1 --openai-key test --openai-voice fable
```

`fake_gemini.py` записує тіла запитів у `fake_gemini_requests.jsonl` — зручно звіряти формат.

## Як це працює всередині

Протокол (little-endian, рядки = 7-бітна довжина + UTF-8):

```
→ int32 1, string talker, string codec, string backend          # Load
← int32 1, int32 1                                              # ok   (або int32 4, string)

→ int32 2, string text, string language,                       # Synth
  int32 refLen, float32[refLen]
← int32 2, int32 count, float32[count]   (повторюється)         # аудіо
← int32 3                                                       # кінець
```

Обмеження, які перевіряються так само, як в оригіналі: текст 1–2000 символів, `refLen` 2400–240000,
разом не більше 720000 семплів, мова — одна з десяти англійських назв.

Гра вбиває процес воркера при скасуванні запиту, тому окремої команди cancel не існує.
Якщо синтез падає, мод віддає 1200 семплів тиші та коректно завершує відповідь — інакше гра
вимикає мовлення до кінця сесії.

```powershell
.\build.ps1             # воркер, плагін та інсталятор → dist\
.\release.ps1           # + перевірка версій і smoke-тест → artifacts\SWYF-CloudTTS-Setup-vX.Y.Z.exe
```

Плагін компілюється проти збірок встановленої гри (`-GameDir`, якщо гра не в типовій бібліотеці Steam).
Воркер публікується як `win-x64` self-contained: .NET на машині гравця не потрібен. Інсталятор
написаний на .NET Framework 4.8, який уже є у Windows 10/11. Версію всіх частин задає
`Directory.Build.props`.
Тримінг вимкнено навмисно — `System.Text.Json` використовує рефлексію.

## Обмеження

- Лише Windows x64 (гра існує тільки там).
- Потрібен інтернет; офлайн-режиму немає (крім `passthrough`).
- Мод не прискорює саму гру — тільки синтез мовлення.
- Клонування голосів ElevenLabs потребує платного плану; Google AI та OpenAI клонування не вміють.
- Qwen3-TTS не має української мови (Auto/English/Russian — найближчі варіанти) і потребує власної
  або орендованої GPU; якість і швидкість залежать від розміру моделі та карти.
- Безкоштовний тариф Google AI має малий добовий ліміт запитів до TTS-моделі; для тривалої гри
  потрібен платний тариф або інший провайдер.
- Steam-оверлей і античіт не зачіпаються: бінарник гри не змінюється, підмінюється лише
  зовнішній процес, який гра сама запускає.
